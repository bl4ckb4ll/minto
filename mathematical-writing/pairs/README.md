# Paired examples

Each example should be one directory or file with a stable identifier.

Suggested fields:

- source
- citation
- redistribution status
- mathematical topic
- level: local / proof / section / chapter / book
- diagnosis
- revision
- operations performed
- preserved content
- possible loss
- reviewer notes

When exact source text cannot be redistributed, store a structural paraphrase plus a precise citation, then write the revised version from that.

Paired examples from the same author are especially valuable: one successful passage and one repairable passage can isolate a writing feature without pretending the author has a single uniform style.
