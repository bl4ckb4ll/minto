# Minto

Notes on writing for the reader: deciding what they need, putting it first, and separating useful context from the writer’s need to unload.

Start with [`principles/reader-first.md`](principles/reader-first.md).

## Reading notes

- [Books index](books/README.md)
- [Barbara Minto, *The Pyramid Principle*](books/barbara-minto-the-pyramid-principle.md)
- [George Orwell, *Homage to Catalonia*](books/george-orwell-homage-to-catalonia.md)

The project is broader than corporate writing. It applies the same reader model to instructions, technical explanations, bug reports, requests, family messages, and other ordinary communication.
