# Books

This directory keeps the longer works behind the writing practice in this repository.

The point is not to build a canon. It is to keep useful sources close enough to argue with, revise, and eventually replace.

## Core books

- **Barbara Minto — _The Pyramid Principle: Logic in Writing, Thinking and Problem Solving_**
  - The source for what is often called the Minto method: lead with the answer, group supporting ideas, and make the hierarchy of the argument visible.
  - The repository name is provisional. Useful practice does not imply permanent deference to its current namesake.
  - See [barbara-minto-the-pyramid-principle.md](barbara-minto-the-pyramid-principle.md).

- **George Orwell — _Homage to Catalonia_**
  - Keep Orwell here as a reporter and participant trying to say plainly what he saw, including uncertainty, faction, contradiction, and error—not merely as the author of _Animal Farm_ or as an adjective ending in “-ian.”
  - See [george-orwell-homage-to-catalonia.md](george-orwell-homage-to-catalonia.md).

## Text policy

This repository should not silently become a dump of copyrighted scans or ebooks. Commit full text only when redistribution is permitted; otherwise keep a bibliographic entry, notes, excerpts within ordinary quotation limits, and lawful acquisition or library links.
